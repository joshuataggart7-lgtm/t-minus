PART A — Fix the NF 1858 memo body

The NF 1858 memo shell is correct. The body is not drafted. Fix:

1. When a memo-type document is opened or generated, run the document drafter for every body section, the same way the JOFOC and TER are drafted. For the Market Research Memorandum: Purpose (one sentence), Requirement (from the record), Research conducted (SAM.gov set-aside evidence search results if run, sources sought if any, prior contract file review, discussions with industry from the record), Findings (number of sources, small business capability, Rule of Two result), Commercial products and services (cross-reference the commerciality determination), Conclusion (consistent with the record's competition and set-aside values: for A-2027-0101 that is competitive, total small business set-aside). Never export a numbered heading with no text under it; if a section can't be drafted from the record, insert "[Contracting officer to complete: <what is missing>]" so the gap is visible.

2. Paragraph 1 must not be a run-on key:value string. Render the record facts as labeled lines (Acquisition, Requirement, Center, Requisition, Mission, Estimated value, NAICS, PSC, Contract type, Competition, Contracting officer), one per line. Show the mission's name, never its code (M1).

3. Default routing for the Market Research Memorandum and the Commerciality Determination is To: Contract File [requisition]; no Thru. Keep Branch Chief / Team Lead routing for the transmittal memo and JOFOC.

4. Keep Distribution on the same page as the signature when it fits. Put the metadata line (file id, citation, "issued on NF 1858", prototype notice) in a small page footer, not in the Distribution block.

5. Export: the memo editor needs visible "Export Word" and "Export PDF" buttons that produce the file server-side or via docx, with no browser print headers or footers.

6. In the launch sequence, "Open the template" on a document line must open that document for the current file (creating it from the template if it doesn't exist yet), not navigate to the Templates library.
