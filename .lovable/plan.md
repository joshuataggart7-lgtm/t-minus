# Sample 1 named DOCX persistence

## Scope
- Update the shared DOCX download helper only.
- Preserve the Sample 1 prefetch, completion messages, citations, Part 15 exports, and all held form paths.

## Implementation
- Copy generated bytes with `bytes.slice()` before creating any browser download payload.
- For DOCX files at or below 512 KB, base64-encode the copied bytes into a DOCX `data:` URL and set the anchor’s explicit `.docx` filename before clicking.
- Keep the existing named `File`/object-URL path for larger DOCX exports.
- Retain delayed cleanup for the object-URL path.
